# CastLink — скачивание

CastLink — бесплатное ПО для видеокомнат и собственной студии. Здесь размещаются установщики и выпуски приложения.

## Скачать

- [Установщик для Windows 10–11](https://github.com/resokol/castlink-releases/releases/latest/download/CastLink-Windows.zip)
- [Серверный пакет для Linux](https://github.com/resokol/castlink-releases/releases/latest/download/CastLink-Linux.tar.gz)
- [Описание последнего выпуска и контрольные суммы](https://github.com/resokol/castlink-releases/releases/latest)

Распакуйте Windows-архив и запустите `EasySetup.exe`. Для консольного мастера используйте `EasySetup-Console.cmd`.

Мастер устанавливает сервер локально на Windows либо на внешний VPS с Ubuntu 22.04/24.04 amd64 через SSH. Для локального сервера используется Docker Desktop; мастер проверяет его наличие и предлагает установку. Для настройки внешнего VPS Docker на компьютере, с которого запущен мастер, не требуется.

Если старый установщик не может проверить обновления, скачайте новый архив по ссылке выше и запустите мастер из него.

## Условия использования

Условия конкретной версии указаны в её пакете и описании выпуска. Ранее опубликованные версии под MIT сохраняют эту лицензию. Сторонние компоненты распространяются на условиях их собственных лицензий.

Этот репозиторий предназначен для распространения готовых пакетов; репозиторий разработки ведётся отдельно.
